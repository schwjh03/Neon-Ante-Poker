# Changes

## 1.1.0

- Added Classic, Daily Seed, Relic Draft, and Echo Table run modes.
- Added Balanced, Planner, and Performer starting styles.
- Added five optional table challenges with one-time payouts.
- Added free relic drafting between blinds in Draft mode.
- Split the market into relics, constellations, deck workshop, and voucher areas.
- Added relic slot movement and genuinely ordered multiplier effects.
- Added local completed-build history and validated .neonbuild export/import.
- Echo targets adapt to strong saved or deliberately imported builds, with a cap.
- Existing version-one saves import into a separate run-v2.save file; the original file is retained.
- Expanded engine regression coverage and rendered UI smoke checks.

Echo is a local, offline system. It does not collect data from the public or upload builds automatically.
